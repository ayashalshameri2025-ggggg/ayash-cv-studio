# AYASH CV STUDIO
**Build Your Career. Design Your Future.**

Developed by **AYASH MAHMOUD ALSHAMERI** — *Software & AI Developer* (`Code meets intelligence`).

## المميزات الرئيسية
- **10 قوالب احترافية مختلفة في البنية والتصميم** (Classic, Executive, Minimal, Creative, ATS, Technical, Academic, Medical, Fresh Graduate, International).
- **محرر ثلاثي الأجزاء** مع معاينة فورية لصفحة A4.
- **دعم كامل للعربية (RTL) والإنجليزية (LTR)**.
- **خصوصية تامة 100%**: لا يوجد خوادم، لا قواعد بيانات، لا LocalStorage، لا Cookies.
- **تصدير حقيقي** بصيغة PDF (نص قابل للبحث والطباعة) وملف Word (.doc) قابل للتعديل.

## طريقة التشغيل محليًا
```bash
npm install
npm run dev
```

## النشر على GitHub و Netlify
1. ارفع هذا المجلد إلى مستودع جديد على GitHub.
2. اربط المستودع بحسابك في Netlify.
3. سيقرأ Netlify ملف `netlify.toml` تلقائيًا وينشر الموقع فورًا.
